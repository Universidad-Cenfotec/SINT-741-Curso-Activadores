## Organizacion

Cada ejemplo o laboratorio va en su propia subcarpeta, con un README propio que indique:

- Que hace el codigo y que concepto del curso ilustra
- Requisitos previos (lenguaje, version, dependencias)
- Como ejecutarlo

## Convencion de nombres

SXX-nombre-del-ejemplo/ — por ejemplo, S03-triggers-basicos/

Usar nombres en minuscula y separados por guiones, sin espacios ni tildes, para evitar problemas al clonar el repositorio en distintos sistemas operativos.
