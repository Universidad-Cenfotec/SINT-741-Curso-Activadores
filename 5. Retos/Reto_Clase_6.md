# Laboratorio 6: ¡De mi proyecto a nuestra comunidad!

**Curso:** SINT-741 – Activadores de Comunidades de Práctica  
**Modalidad:** Individual  
**Duración:** 60 minutos  
**Herramientas:** GitHub y una herramienta de inteligencia artificial (ChatGPT, Claude o Gemini).

## Objetivo

Crear un repositorio personal en GitHub a partir de un proyecto propio, documentándolo de manera que otras personas puedan comprenderlo, utilizarlo y contribuir a su desarrollo.

## Descripción del reto

En la clase anterior exploramos cómo distintas comunidades comparten sus conocimientos, proyectos y experiencias mediante repositorios abiertos.

Ahora es tu turno de convertirte en creador.

Selecciona un proyecto personal y construye un repositorio en GitHub que permita compartirlo con otras personas.

Puedes trabajar con un proyecto de desarrollo de software, robótica, electrónica, educación, investigación, una iniciativa social, cultural o cualquier otra área de tu interés.

**Importante:** Tu proyecto no necesita estar terminado. Puede encontrarse en una etapa inicial, siempre que tengas una idea concreta y puedas explicar qué has desarrollado, qué deseas lograr y cómo otras personas podrían colaborar.

## Instrucciones

### Fase 1. Crear tu repositorio (10 minutos)

1. Ingresa a https://github.com e inicia sesión.
2. Selecciona **New repository**.
3. Asigna un nombre claro y representativo a tu proyecto.
4. Agrega una breve descripción.
5. Define si será público o privado.
6. Activa la opción para crear un archivo README.
7. Crea tu repositorio.

### Fase 2. Documentar tu proyecto (15 minutos)

Utilizando Markdown, desarrolla el archivo `README.md` con los siguientes apartados:

- **Nombre del proyecto:** ¿Cómo se llama?
- **Descripción:** ¿En qué consiste?
- **Problema o necesidad:** ¿Qué busca solucionar?
- **Público objetivo:** ¿A quién está dirigido?
- **Origen:** ¿Cómo nació la idea?
- **Estado actual:** ¿Qué has desarrollado hasta ahora?
- **Cómo comenzar:** ¿Qué necesita saber alguien que quiera utilizarlo o explorarlo?
- **Próximos pasos:** ¿Qué te gustaría mejorar?

Puedes agregar imágenes, diagramas, fotografías u otros materiales que ayuden a comprender tu proyecto.

También puedes apoyarte en inteligencia artificial para organizar y mejorar la redacción, verificando siempre que la información sea correcta.

### Fase 3. Preparar tu proyecto para recibir contribuciones (10 minutos)

**Actividad A: Crear CONTRIBUTING.md**

Crea un archivo llamado `CONTRIBUTING.md` que explique cómo otras personas podrían:

- Proponer ideas o mejoras.
- Reportar errores.
- Contribuir con documentación o recursos.
- Solicitar la incorporación de cambios.

**Actividad B: Crear un Issue**

Ingresa a la pestaña **Issues** de tu repositorio y registra una mejora pendiente.

El Issue debe contener un título descriptivo, una explicación de lo que se necesita y el resultado esperado.

Ejemplo:

**Título:** Agregar imágenes del prototipo.

**Descripción:** El proyecto cuenta con instrucciones escritas, pero necesita fotografías que faciliten la comprensión de sus componentes.

**Resultado esperado:** Incorporar al menos una imagen con una descripción clara.

### Fase 4. Realizar tu primera contribución mediante Pull Request (15 minutos)

Aunque el trabajo es individual, practicarás el proceso que seguiría cualquier persona interesada en contribuir a tu proyecto.

1. Crea una nueva rama (*branch*) dentro de tu repositorio.
2. Realiza una mejora sencilla en uno de los archivos.
3. Guarda los cambios mediante un *commit*.
4. Abre un **Pull Request** desde tu nueva rama hacia la rama principal.
5. Explica qué modificación realizaste y por qué es importante.
6. Revisa los cambios propuestos.
7. Integra el Pull Request a la rama principal (*merge*).

**Importante:** No necesitas trabajar con otra persona. En este ejercicio practicarás individualmente el flujo de contribución y revisión. La revisión será una autoevaluación, no una revisión entre pares.

### Fase 5. Presentar tu resultado (3 minutos)

Prepara una explicación breve de tu proyecto respondiendo:

1. ¿Qué proyecto seleccionaste y por qué?
2. ¿Qué mejora propusiste mediante el Issue?
3. ¿Cómo podría crecer tu proyecto con futuras contribuciones?

## Uso de inteligencia artificial

Puedes utilizar ChatGPT, Claude o Gemini como asistentes durante el laboratorio.

La inteligencia artificial puede ayudarte a redactar documentación, organizar ideas y preparar instrucciones de colaboración.

Sin embargo, debes verificar sus respuestas y asegurarte de que no invente funcionalidades, experiencias ni resultados.

Incluye en tu README una breve descripción de cómo utilizaste la IA.

## Entregable

Comparte **el enlace de tu repositorio personal de GitHub**.

Tu repositorio debe contener:

- [ ] Un archivo `README.md` con la descripción del proyecto.
- [ ] Un archivo `CONTRIBUTING.md` con instrucciones para colaborar.
- [ ] Al menos un Issue con una propuesta de mejora.
- [ ] Al menos un Pull Request creado e integrado.
- [ ] Una breve declaración del uso de inteligencia artificial.

Si tu repositorio es privado, deberás facilitar acceso a la docente para su revisión.

No publiques contraseñas, información confidencial ni materiales de terceros sin autorización.

## Reflexión final

**¿Qué necesita tener tu proyecto para que otra persona pueda comprenderlo, utilizarlo y mejorarlo sin depender de ti?**

Recuerda que una comunidad de práctica no se construye únicamente compartiendo conocimientos, sino creando oportunidades para que otras personas puedan aprender, contribuir y continuar lo que hemos comenzado.

**¡Un proyecto crece cuando otros pueden continuarlo!**
