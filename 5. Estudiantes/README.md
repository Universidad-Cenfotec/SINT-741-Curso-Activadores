# 5. Estudiantes

Espacio para los trabajos, entregas y aportes de los estudiantes del curso SINT-741 — Curso Activadores.

## Contenido

| Estudiante o equipo | Trabajo | Sesion |
|---------------------|---------|--------|
| — | — | — |

## Organizacion

Cada estudiante o equipo trabaja en su propia subcarpeta, identificada por usuario de GitHub o nombre de equipo. Dentro de cada subcarpeta conviene incluir un README que indique el nombre, la entrega correspondiente y como ejecutar o revisar el trabajo.

## Convencion de nombres

Nombres en minuscula, separados por guiones, sin espacios ni tildes.

## Sobre datos personales

Este repositorio es publico. Evitar subir carnes, correos, numeros de identificacion, fotos u otros datos personales de los estudiantes; basta con el usuario de GitHub o el nombre de pila para identificar las entregas.
