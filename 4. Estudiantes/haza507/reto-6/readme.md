# Bit a Bit

Recursos abiertos de Informática para primaria, pensados principalmente para Panamá.

## Descripción

**Bit a Bit** es un proyecto para reunir y compartir recursos de Informática para primaria: fichas de clase, actividades y rúbricas que cualquier docente pueda consultar, usar y adaptar.

Los recursos toman como referencia los programas de MEDUCA (Panamá). Docentes de otros países pueden usarlos también, adaptándolos a su propio plan de estudios.

## Problema o necesidad

En el sector público hay pocos recursos de Informática para primaria, y los planes de estudio no siempre indican con claridad cómo llevar los temas a actividades concretas en el aula.

## Público objetivo

Docentes de Informática de primaria, principalmente en Panamá, aunque el proyecto está abierto a docentes de cualquier país.

## Origen

La idea nace de la experiencia como docente de Informática en primaria del sector público, al notar la falta de recursos y la poca claridad de los planes de estudio.

## Estado actual

El proyecto está en **fase inicial**. Por ahora existe la idea, este README y la guía de contribución ([CONTRIBUTING.md](CONTRIBUTING.md)). Todavía no se han publicado recursos.

## Cómo comenzar

Si quieres explorar o colaborar:

1. Lee este README para entender el propósito del proyecto.
2. Revisa la pestaña **Issues** para ver las mejoras pendientes y las ideas en discusión.
3. Lee [CONTRIBUTING.md](CONTRIBUTING.md) para saber cómo proponer ideas, reportar errores o aportar recursos.

## Próximos pasos

1. Definir una plantilla común para las fichas: grado, tema, objetivo, materiales, desarrollo de la clase, evaluación y rúbrica.
2. Publicar las primeras fichas para 3º a 6º grado, empezando por **dispositivos de entrada, salida y almacenamiento** y **ciudadanía digital**.
3. Organizar los recursos por grado y por tema.
4. Incorporar una sección de **pensamiento computacional y micro:bit**.
5. Publicar los recursos en un sitio web para facilitar su consulta.
