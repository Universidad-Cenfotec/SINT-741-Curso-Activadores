# Mapa de comunidad

## Dominio: qué nos une

**Construir robots educativos con la IdeaBoard usando piezas impresas en 3D que se puedan compartir y combinar.**

La necesidad viene de los talleres: cada grupo resuelve el montaje de la placa por su cuenta y esas soluciones no se reutilizan. Un estándar abierto (una carcasa y una sola forma de acoplar piezas) permite que el trabajo de un grupo sirva al siguiente.

## Quiénes participan

| Perfil | Qué busca | Qué puede aportar |
|---|---|---|
| Estudiante que empieza en robótica | Armar un robot que funcione | Pruebas, fotos, preguntas |
| Docente o facilitador de taller | Material listo para usar en clase | Actividades, retroalimentación de grupos |
| Maker con impresora 3D | Proyectos para imprimir y mejorar | Pruebas de ajuste, mejoras de impresión |
| Diseñador CAD | Un estándar sobre el cual crear | Nuevos módulos |
| Programador | Ejemplos para la IdeaBoard | Código para cada módulo |

## Trayectorias de participación

Cada paso es pequeño y deja algo útil en el repositorio.

```
 EXPLORAR ──► PROBAR ──► CONTRIBUIR ──► CREAR ──► LIDERAR
 leer el      imprimir   abrir un       diseñar   revisar aportes,
 README       la tapa    issue con su   un módulo coordinar una
 (5 min)      (1 h)      prueba         nuevo     versión o un taller
```

| Paso | Primera acción concreta | Señal de que lo lograste |
|---|---|---|
| Explorar | Leer el README y la tabla de estado | Sabés qué existe y qué falta |
| Probar | Seguir la [ficha de fabricación](../recursos/carcasa-ideaboard.md) | Tenés una tapa impresa sobre tu placa |
| Contribuir | Abrir un issue con la plantilla "Prueba de ajuste" | Tu medición queda registrada |
| Crear | Diseñar un módulo según el [estándar de acople](estandar-de-acople.md) | Se aprueba tu pull request con STL e imágenes |
| Liderar | Asumir uno de los roles de abajo | Figurás en la tabla de responsables |

## Roles

| Rol | Responsabilidad | Dedicación aprox. |
|---|---|---|
| Mantenedor/a | Revisar pull requests y publicar versiones | 1 h/semana |
| Curador/a de módulos | Comprobar que los módulos nuevos cumplan el estándar y estén documentados | Cuando llegan aportes |
| Facilitador/a de taller | Usar ModuBot en clase y traer la retroalimentación al repositorio | Por taller |
| Bienvenida | Responder los primeros issues de personas nuevas y etiquetar "buen primer aporte" | 30 min/semana |
