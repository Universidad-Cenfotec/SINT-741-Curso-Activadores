
# Guía de bienvenida en español para OpenQuadruped

**Grupo 5 — Activación Comunitaria**

## 1. ¡Bienvenido a OpenQuadruped!

Esta guía está dirigida a personas interesadas en explorar el mundo de la robótica, la programación, la electrónica y la fabricación digital.

Nuestro objetivo es ayudarte a comprender qué es OpenQuadruped, conocer los recursos disponibles e identificar cómo puedes participar en el proyecto, incluso si no tienes experiencia previa en robótica.

## 2. ¿Qué es OpenQuadruped?

OpenQuadruped es un proyecto abierto de un robot de cuatro patas que utiliza piezas impresas en 3D y herramientas de software para controlar sus movimientos.

El proyecto aborda el reto de coordinar el movimiento de las patas y modificar la posición y orientación del cuerpo del robot.

Puedes conocer más sobre el proyecto en su [repositorio oficial de GitHub](https://github.com/adham-elarabawy/open-quadruped).

## 3. ¿Qué necesitas para comenzar?

Para realizar este recorrido inicial solamente necesitas:

- Una computadora o dispositivo con acceso a internet.
- Un navegador web.
- Interés en aprender y explorar el proyecto.
- Una cuenta de GitHub si deseas realizar contribuciones.

No necesitas tener un robot, una impresora 3D ni conocimientos avanzados de programación para comenzar a explorar la documentación.

## 4. Conceptos básicos

Antes de explorar el proyecto, es importante conocer algunos términos:

| Concepto | Significado |

## 5. Primer recorrido por el proyecto

### Paso 1. Explora el repositorio

Ingresa al [repositorio de OpenQuadruped](https://github.com/adham-elarabawy/open-quadruped).

Encontrarás los archivos, las carpetas, la documentación y los espacios de colaboración del proyecto.

### Paso 2. Lee el README

Consulta el [README del proyecto](https://github.com/adham-elarabawy/open-quadruped/blob/master/README.md).

Este documento te permitirá conocer:

- La descripción general del robot.
- Los recursos disponibles.
- Las tareas pendientes.
- Algunas limitaciones del proyecto.

### Paso 3. Consulta la documentación

Ingresa a la [Wiki de OpenQuadruped](https://github.com/adham-elarabawy/open-quadruped/wiki).

Allí encontrarás información relacionada con diferentes aspectos técnicos.

| Recurso | ¿Qué puedes encontrar? |
| --- | --- |
| [Networking Setup](https://github.com/adham-elarabawy/open-quadruped/wiki/Networking-Setup) | Referencias sobre la configuración de red. No es una guía exhaustiva. |
| [ROS Node Infrastructure](https://github.com/adham-elarabawy/open-quadruped/wiki/ROS-Node-Infrastructure) | Documentación relacionada con la estructura de control mediante ROS. |
| [Wiring Diagram](https://github.com/adham-elarabawy/open-quadruped/wiki/Wiring-Diagram) | Información sobre el cableado, que puede variar según los componentes utilizados. |

### Paso 4. Identifica las carpetas principales

En el repositorio encontrarás carpetas como:

- `control_library/`
- `llc-teensy/`
- `ros-workspace/`
- `vis-tool/`

Estas carpetas forman parte de los recursos técnicos del proyecto.

Su contenido completo, funcionamiento y ejecución no han sido verificados por nuestro grupo.

### Paso 5. Revisa la licencia

Antes de reutilizar archivos o realizar modificaciones, consulta el [archivo LICENSE](https://github.com/adham-elarabawy/open-quadruped/blob/master/LICENSE).

El archivo se titula MIT License, pero incluye una condición adicional que exige reconocer de manera explícita y formal la autoría de Adham Elarabawy.

Es importante consultar y respetar las condiciones completas del archivo original.

## 6. ¿Cómo puedes participar?

No todas las contribuciones requieren conocimientos avanzados de programación o robótica.

Puedes elegir una actividad según tus intereses y habilidades.

| Si te interesa... | Puedes contribuir mediante... |
| --- | --- |
| Documentación | Mejorar explicaciones o instrucciones. |
| Traducción | Adaptar información al español. |
| Investigación | Revisar fuentes y recursos disponibles. |
| Diseño | Proponer mejoras en la presentación de la documentación. |
| Programación | Explorar el código e identificar posibles mejoras. |
| Electrónica | Revisar la documentación técnica y formular preguntas. |
| Aprendizaje | Compartir dudas y dificultades encontradas durante el recorrido. |

### ¿Dónde puedes compartir tus aportes?

- [Issues](https://github.com/adham-elarabawy/open-quadruped/issues): para comunicar problemas, dudas o sugerencias.
- [Pull Requests](https://github.com/adham-elarabawy/open-quadruped/pulls): para presentar cambios que puedan ser revisados.

Antes de abrir una Issue, revisa si otra persona ya reportó el mismo problema.

Si todavía no sabes utilizar GitHub, puedes consultar nuestro recurso [Errores comunes de los principiantes en GitHub](errores-comunes-github-principiantes.md).

## 8. Primera actividad de participación

### Explora, aprende y comparte

**Objetivo:** familiarizarte con el proyecto e identificar una oportunidad de colaboración.

**Duración estimada:** 15 a 20 minutos.

**Materiales:** dispositivo con internet y esta guía.

### Instrucciones

1. Ingresa al repositorio de OpenQuadruped.
2. Lee la presentación del proyecto en el README.
3. Explora uno de los recursos de la wiki.
4. Identifica una duda, dificultad o posible mejora.
5. Registra tu observación utilizando la siguiente plantilla.
6. Comparte tu aporte con nuestra comunidad.
