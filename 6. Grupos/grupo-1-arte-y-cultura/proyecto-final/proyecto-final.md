# Primer Encuentro

**Proyecto final · SINT-741 Activadores de Comunidades de Práctica · Universidad Cenfotec**
Modalidad **grupal** · **Grupo 1, Arte y Cultura**
Basado en la consigna [Proyecto final · mi-comunidad](https://github.com/Universidad-Cenfotec/SINT-741-Curso-Activadores/blob/main/5.%20Retos/Proyecto_Final_mi-comunidad.md)

Comunidad de práctica para quienes coordinan un proyecto, club, aula o iniciativa y quieren **reunir a su gente por primera vez, repartir responsabilidades y dejar un registro**, aunque nunca hayan organizado nada. Nuestro punto de partida es la [Guía para organizar un primer encuentro](../reto-03/guia-primer-encuentro-y-responsabilidades.md) del Reto 3.

## Empieza en 3 pasos

1. **Lee la guía** y escribe el propósito de tu encuentro en una frase: *Queremos que ______ pueda ______.*
2. **Copia las [plantillas](#plantillas-para-tu-primer-encuentro)** (invitación, roles, agenda y acta) y organiza tu encuentro.
3. **Cuéntanos qué pasó:** qué agenda usaste, qué rol faltó o sobró y cuánto duró.

## Entrega 1 · Mapa de Comunidad

### Dominio

**Organizar encuentros comunitarios y repartir responsabilidades** para que un grupo pueda reunirse, decidir y continuar sin depender de una sola persona.

**Necesidad real.** Lo vivimos en el propio Grupo 1: en el Reto 2 quedaron responsables «por confirmar», no estaba claro quién tenía permisos para editar y el plan dependía de que Mario estuviera. La prueba de *Tú Decides* con personas se propuso para un sábado y nunca se concretó. Faltaba un procedimiento sencillo para pasar de la idea al encuentro.

### Intención, función y prueba

> Queremos crear **una guía y unas plantillas para un primer encuentro** para que **quien coordina un proyecto, club, aula o iniciativa, aunque no tenga experiencia,** pueda **reunir a su grupo, repartir roles con suplente y dejar un acta sin que nadie se lo explique**.

- **Función.** En unos 20 minutos de preparación, tener fecha, invitación, roles aceptados, agenda y acta.
- **Prueba.** Alguien que no organizó el encuentro anterior usa la guía y prepara el siguiente; el encuentro termina con próxima acción, responsable y fecha.

### Participantes

|---|---|---|---|

### Plantillas para tu primer encuentro

Copia, completa y usa. Las explicaciones de cada paso están en la [Guía para organizar un primer encuentro](../reto-03/guia-primer-encuentro-y-responsabilidades.md).

> **Origen:** extraídas de la guía del Reto 3 para que se puedan usar sin leerla completa. **Estado:** aún sin probar en un encuentro real.

#### 1. Propósito en una frase

```
Queremos que ______________________ pueda ______________________.
```

#### 2. Invitación

```
Hola. Te invito a un encuentro de 60 minutos el [día] a las [hora] en [lugar o enlace].
Vamos a [actividad] y a conversar sobre qué mejorar. No necesitas experiencia previa.
Si quieres ayudar, puedes [acción pequeña: probar, traer una idea, acompañar a alguien].
Cualquier duda, escríbele a [nombre].
```

#### 3. Roles

Cada persona acepta su rol de forma expresa. Si son tres, alcanza con facilitación, documentación y observación.

| Rol | Titular | Suplente | ¿Aceptó? |
|---|---|---|---|
| Convocatoria | | | [ ] |
| Facilitación | | | [ ] |
| Documentación | | | [ ] |
| Observación | | | [ ] |
| Acompañamiento | | | [ ] |
| Seguimiento | | | [ ] |
| Coordinación alternativa | | | [ ] |

#### 4. Agenda de 60 minutos

| Tiempo | Qué se hace |
|---|---|
| 0–10 min | Bienvenida: nombre y algo que sabe hacer cada persona. |
| 10–20 min | Propósito y formas de participar. |
| 20–45 min | La actividad acordada. |
| 45–55 min | ¿Qué funcionó? ¿Qué costó? ¿Qué cambiaríamos? |
| 55–60 min | Acuerdos: próxima acción, responsable y fecha. |

#### 5. Acta

```markdown
## Encuentro del [fecha]
- Asistentes (sin nombres de menores):
- Qué hicimos:
- Qué funcionó:
- Qué costó o qué dudas hubo:
- Una dificultad y el cambio que acordamos (quién, para cuándo):
- Acuerdos:  [ ] acción — responsable — fecha
- Próximo encuentro:
```

#### 6. Cierre (48 horas después)

- [ ] Envié el resumen a todas las personas.
- [ ] Recordé los acuerdos.
- [ ] Publiqué el acta donde todos la pueden leer.
- [ ] Hay una persona distinta para convocar o facilitar el siguiente encuentro.

## Entrega 3 · Plan de evolución y sostenibilidad

### Responsabilidades compartidas

Usamos nuestra propia guía: cada rol tiene titular y suplente, se acepta de forma expresa y rota.

| Rol | Qué hace | Rotación |
|---|---|---|
| Coordinación | Fija la fecha del siguiente encuentro y cuida los acuerdos. Jimena es la segunda coordinadora. | Cada encuentro |
| Facilitación | Guía el encuentro con la agenda de 60 minutos. | Cada encuentro |
| Documentación | Escribe el acta y la agrega a la [bitácora](#bitácora-de-activación) en 48 horas. | Cada encuentro |
| Observación | Anota duración real, roles que faltaron o sobraron y dudas. | Cada encuentro |
| Bienvenida | Responde los Issues nuevos en menos de una semana. Empieza Paula. | Mensual |
| Mantenimiento | Revisa Pull Requests y actualiza la guía con lo aprendido. | Mensual |

**Si quien coordina no está:** cualquier integrante abre la guía y las plantillas y prepara el siguiente encuentro.

### Próximos rituales

| Cuándo | Qué | Responsable |
|---|---|---|
| Por acordar en el grupo | Ensayo entre integrantes con la guía y *Tú Decides* | Coordinación |
| Después del ensayo | Ajustar agenda y roles según la duración real | Mantenimiento |
| Mes siguiente | Primer encuentro con personas ajenas al grupo | Quien no haya coordinado el ensayo |
| Después | Probar la guía con otra comunidad (un club o un aula) | Quien lo proponga en un Issue |

### Cómo recibir a nuevos miembros

1. Leer este documento y la guía.
2. Presentarse en un Issue: qué grupo quiere reunir.
3. Usar las [plantillas](#plantillas-para-tu-primer-encuentro) para su primer encuentro.
4. Compartir el acta y una mejora para la guía.

### Señales reales de comunidad

| Señal real | Cómo la observamos |
|---|---|
| Uso por otras personas | Alguien fuera del Grupo 1 organiza un encuentro con la guía y lo cuenta. |
| Facilitación distribuida | El siguiente encuentro lo convoca o facilita una persona distinta. |
| Recurrencia | Las mismas personas vuelven al segundo encuentro. |
| Ayuda entre pares | Alguien responde la duda de otra persona sobre la guía. |
| Mejora del recurso | Un cambio aceptado que nace de una experiencia real. |

**Métricas de vanidad que no usaremos como prueba:** estrellas, visitas, seguidores o mensajes sin acción.

### Cómo copiar o continuar la comunidad

1. Copia este documento y la guía en tu propio espacio (un *fork* o un documento compartido).
2. Cambia la actividad de ejemplo por la de tu grupo.
3. Organiza tu encuentro con las plantillas.
4. Registra lo que pasó en la bitácora.
5. Cuéntanos en un Issue para enlazar tu versión.

## Bitácora de activación

Registramos solo lo que ocurrió. Lo pendiente se marca como pendiente.

### 1. Origen: la organización del Reto 2 · 8 de octubre de 2026

- **Quién:** Grupo 1, en clase.
- **Qué hicimos:** repartimos roles para trabajar *Tú Decides*: facilitó Melvin, documentó Mario, observó Maykol y Jimena quedó como segunda coordinadora.
- **Qué pasó:** funcionó para la clase, pero dejamos responsables «por confirmar», no sabíamos quién tenía permisos para editar y la prueba con personas quedó sin fecha.
- **Ajuste:** con eso escribimos la [guía](../reto-03/guia-primer-encuentro-y-responsabilidades.md) en el Reto 3: suplente por rol, roles aceptados de forma expresa y confirmar permisos de edición.

### 2. Primer encuentro usando la guía · pendiente

**Estado: no se ha realizado.** La agenda de 60 minutos, la invitación y el acta todavía no se han usado.

**Qué haremos:** un **ensayo** entre integrantes del grupo, organizado con las [plantillas](#plantillas-para-tu-primer-encuentro), con *Tú Decides* como actividad.

**Hipótesis:** el encuentro durará más de 60 minutos y la tabla de seis roles será demasiada para un grupo pequeño.

> Cuando se haga, se registra abajo con la plantilla.

## Cómo participar

No hace falta experiencia organizando ni saber programar. Una pregunta, una corrección o contarnos cómo te fue también son aportes.

### Escalera de participación

| Escalón | Qué haces | Cómo se ve en GitHub |
|---|---|---|
| 1 · Leo | Leo la guía y las plantillas. | Lees este documento o los Issues. |
| 2 · Pregunto | Digo qué no se entiende o qué me trabó al leer. | Abres un Issue `[Duda]`. |
| 3 · Uso | Organizo un encuentro con la guía. | Abres un Issue `[Experiencia]` con el acta, sin nombres de menores. |
| 4 · Mejoro | Corrijo una frase, agrego un ejemplo o una plantilla. | Envías un Pull Request. |
| 5 · Acompaño | Ayudo a otra persona a organizar su primer encuentro o reviso sus cambios. | Respondes Issues y revisas Pull Requests. |

Puedes subir o bajar de escalón cuando quieras.

### Abrir un Issue

1. Ve a **Issues → New issue**.
2. Usa un título claro: `[Duda] ¿Qué hago si solo somos dos?`, `[Experiencia] Primer encuentro del club de lectura`.
3. Si usaste la guía, cuenta: qué agenda usaste, qué rol faltó o sobró, cuánto duró y qué cambiarías.

### Enviar un cambio (Pull Request)

1. Haz un *fork* del repositorio del curso.
2. Edita la guía o las plantillas. Si agregas un recurso nuevo, indica **su origen**: qué duda, error o experiencia lo produjo.
3. Marca si lo que agregas está **probado** o **sin probar**.
4. Envía el Pull Request explicando qué cambiaste y por qué. Otra persona del grupo lo revisa.

### Acuerdos

- Comentamos el trabajo, no a la persona.
- Cada rol se acepta de forma expresa; nadie queda asignado por suposición.
- Distinguimos lo probado de lo pendiente.
- Cada aporte conserva su autoría.
- No publicamos nombres ni fotos de menores, ni fotos de otras personas sin permiso.
