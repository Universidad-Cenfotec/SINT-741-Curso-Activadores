## Organizacion

- index.html como punto de entrada del sitio
- Recursos estaticos (CSS, JS, imagenes) en subcarpetas: css/, js/, img/
- Rutas relativas en todos los enlaces, para que las paginas abran tanto localmente como publicadas

## Publicacion

GitHub Pages solo permite publicar desde la raiz del repositorio o desde una carpeta llamada exactamente docs. Para publicar el contenido de esta carpeta habria que renombrarla a docs, o configurar un flujo de GitHub Actions que la despliegue.
